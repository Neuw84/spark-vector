spark-vector

A JVM-native vectorized execution engine for Apache Spark SQL. Core operators run on Arrow-layout columnar batches with the Java Vector API — on the JVM, no native code, no JNI — with its own columnar shuffle over Arrow Flight.

Get started See the benchmarks GitHub

Add the plugin to an existing Spark job — no code changes. Register it with spark.plugins=io.sparkvector.spark.VectorPlugin, and turn on the columnar shuffle with spark.shuffle.manager=org.apache.spark.sql.vector.shuffle.VectorShuffleManager and spark.vector.shuffle.enabled=true (the spark-vector-shuffle jar on the classpath), as in the launch below.

spark-submit — spark-vector
Launching Apache Spark with the spark-vector plugin and its Arrow Flight columnar shuffle.
